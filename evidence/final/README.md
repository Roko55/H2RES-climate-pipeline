# Current national planning evidence

Current 42-window extract for seven national planning paths after one calibrated
2020 base. annual_results.json contains additions, generation, demand, policy
checks, annual cost components and selected solution audits. The original
completion receipt and 42 calendar-ledger hashes are preserved alongside it.

Figures 7-15 report annual costs and realized decision-year additions. Annual
capital payments include surviving previous additions. The discounted two-year
solver objective is not relabelled as an annual bill. A new solve requires the
external native database and licensed optimizer. Public result reproduction
requires neither. Earlier thermal/calibrated evidence remains archived.
The 45 original operating checks concern separate electricity portfolios.
